# Oasis-Infobyte-data-anlaytics-Internship
# 📊 Data Science Internship Portfolio

This repository contains three Data Science internship projects that demonstrate practical skills in data analysis, machine learning, data visualization, and business insight generation using Python.

The projects cover Exploratory Data Analysis (EDA), Customer Segmentation using K-Means Clustering, and House Price Prediction using Linear Regression.

---

## 🚀 Projects Included

### 1️⃣ EDA on Retail Sales Data

**Objective**

Perform Exploratory Data Analysis (EDA) on a retail sales dataset to discover sales patterns, customer behavior, and actionable business insights.

**Key Features**

- Data Cleaning & Preprocessing
- Descriptive Statistics
- Monthly & Quarterly Sales Analysis
- Customer Demographics Analysis
- Product Performance Analysis
- Correlation Heatmap
- Business Insights & Recommendations

**Tools & Technologies**

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

---

### 2️⃣ Customer Segmentation using K-Means Clustering

**Objective**

Segment customers into meaningful groups based on purchasing behavior using the K-Means clustering algorithm.

**Key Features**

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Scaling
- Elbow Method
- K-Means Clustering
- Cluster Visualization
- Customer Segment Analysis
- Business Recommendations

**Tools & Technologies**

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

---

### 3️⃣ House Price Prediction using Linear Regression

**Objective**

Develop a machine learning model to predict house prices based on various property features using Linear Regression.

**Key Features**

- Data Cleaning & Preprocessing
- Exploratory Data Analysis
- One-Hot Encoding
- Correlation Analysis
- Linear Regression Model
- Model Evaluation (MSE, RMSE & R²)
- Residual Analysis
- Feature Importance
- Ridge Regression Comparison

**Tools & Technologies**

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab
